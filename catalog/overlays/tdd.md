## Project compatibility

Confirm the seams under test with the user only when the task, its existing
tests, or the project layout does not already establish them; otherwise state
the seams you chose and continue. Upstream keeps refactoring out of the
red → green loop; when project rules ask you to refactor touched code once tests
pass, do it after green and before the next slice. The `codebase-design` and
`code-review` skills are optional: continue without them when they are not
installed, and read an installed skill's `SKILL.md` directly when the agent has
no Skill tool. Read `GLOSSARY.md` and ADRs only when the project has them.
